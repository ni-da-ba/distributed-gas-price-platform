# Authorship and provenance

The underlying university-project concept was developed collaboratively in 2024 by
Nicholas Babineaux and Konner Feldman. That project explored a containerized backend for
querying gasoline-price data and deploying services to Kubernetes.

This repository is a new portfolio implementation written by Nicholas Babineaux in 2026.
It preserves the high-level problem and system topology while replacing the application
source, tests, documentation, container configuration, and Kubernetes manifests. It does
not contain the original collaborator's source code, prose, Git history, or commit identity.

The distinction is intentional:

- **2024:** jointly developed course-project concept and deployment experience.
- **2026:** independent implementation, testing, security hardening, documentation, and
  portfolio maintenance represented by this repository.
